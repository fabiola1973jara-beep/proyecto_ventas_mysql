# Proyecto Ventas MySQL

Este proyecto fue creado por **Liss Fabiola (@LissAlex2803-dotcom)** desde Ubuntu para practicar **SQL y Git**.

## 📘 Descripción
El objetivo es construir una base de datos de ventas con tablas relacionadas, claves foráneas y scripts de revisión.

## 📂 Archivos incluidos
- `01_creacion_tablas.sql` → creación inicial de tablas  
- `02_tablas_revision.sql` → revisión y ajustes  
- `03_tablas_revision.sql` → segunda revisión  
- `04_tablas.sql` → estructura final  
- `05_errores.sql` → corrección de errores  
- `06_alter_foreign.sql` → relaciones entre tablas  
- `Readme.md` → documentación del proyecto  

## ⚙️ Tecnologías utilizadas
- **MySQL Workbench**
- **Ubuntu Terminal**
- **Git y GitHub**

## 🚀 Cómo ejecutar
1. Clona el repositorio:
   ```bash
   git clone git@github.com:LissAlex2803-dotcom/proyecto_ventas_mysql.git
   
   2- Abre los archivos .sql en MySQL Workbench.

   3- Ejecuta los scripts en orden para crear y revisar las tablas.

   🧠 Aprendizaje:

Este proyecto forma parte de la práctica de bases de datos relacionales y control de versiones con Git.
